Dúvidas

Preciso de internet para usar?

PetAgenda e PhotoFesta rodam no seu computador e guardam seus dados lá. O PetAgenda Mobile roda no celular, funciona sem internet depois da primeira abertura e guarda os dados no próprio aparelho. A internet só é necessária para o link público de agendamento ou para os convidados enviarem fotos.

O que acontece quando a licença vence?

Há 3 dias de tolerância. Depois o programa fica só para consulta: você não perde nenhum dado e volta a usar tudo ao renovar.

Posso testar antes de pagar?

Sim. Todo programa começa com 14 dias de teste. Peça o link pelo WhatsApp.

Como renovo?

Chame no WhatsApp. Uma nova chave soma ao tempo que ainda restar.

PetAgenda Mobile e PetAgenda do computador usam os mesmos dados?

Não. Cada um guarda os dados no próprio aparelho e eles não sincronizam entre si. O ideal é a recepção usar o computador e a equipe de banho usar o celular, cada um com a sua rotina, ou usar só o Mobile se você trabalha sozinho(a). Faça backup com frequência: no Mobile os dados só existem no celular.

Qual a diferença de preço entre o PC e o celular?

O PetAgenda do computador (R$ 39,90/mês) inclui o link de agendamento online para os seus clientes. O PetAgenda Mobile (R$ 24,90/mês) é a agenda para quem atende pelo celular. Quem quer os dois leva o combo por R$ 54,90/mês.
